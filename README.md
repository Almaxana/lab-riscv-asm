## Реализация на ассемблере RISC-V
Файл: [`main.s`](main.s)

Функция `fmi`:

**Входные аргументы:**

| Регистр | Назначение |
|---|---|
| `a0` | адрес начала массива |
| `a1` | число строк (M) |
| `a2` | число столбцов (N) |

**Возвращаемые значения:**

| Регистр | Назначение |
|---|---|
| `a0` | номер строки максимального элемента (`-1`, если массив пуст) |
| `a1` | номер столбца максимального элемента (`-1`, если массив пуст) |

**Временные регистры:**

| Регистр | Назначение |
|---|---|
| `t0` | указатель на текущий элемент |
| `t1` | индекс строки текущего максимума (`max_i`) |
| `t2` | индекс столбца текущего максимума (`max_j`) |
| `t3` | значение текущего максимума (`max_el`) |
| `t4` | счётчик строк `i` |
| `t5` | счётчик столбцов `j` |
| `t6` | значение текущего элемента |

Вызов: `jal ra, fmi`, возврат: `ret`.
Функция использует только временные регистры,
поэтому сохранение на стеке не требуется.

Возвращает индекс первого вхождения max элемента.

## Реализация на Си

## Компиляция и дамп
```bash
riscv64-unknown-elf-gcc -march=rv32i -mabi=ilp32 main.c -o output.elf
riscv64-unknown-elf-objdump -D output.elf > output.dump
```
